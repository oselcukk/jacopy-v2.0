# jacopy

Symbolic computation for graded algebra, brackets, and Cartan calculus
with step-by-step proofs.

Covers Lie, Schouten-Nijenhuis, Koszul, Courant and Dorfman brackets;
Cartan relations; Hamiltonian vector fields; and the derived bracket
framework that unifies Poisson, Koszul and Courant brackets under a
single theorem.

See `plan.md` for the design document.

Pre-alpha. Under active construction.
